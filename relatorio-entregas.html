01 — VISÃO GERAL

O que a Novva Visão vende

Não é “fazer site”. É colocar uma empresa para vender pelo WhatsApp com processo: uma página que converte, rastreamento que mostra o que funciona, e um CRM onde nenhuma conversa se perde. O site é a porta de entrada; o CRM é o que sustenta a mensalidade.

Toda a stack abaixo já foi construída e testada num projeto real (Congresso Câncer 2026): landing com rastreamento duplo, funil de captação, painel de ROI, e um CRM de WhatsApp com API oficial da Meta recebendo mensagens 24h/dia. Cada peça vira um serviço vendável.

02 — AS ENTREGAS EM DETALHE

Serviço a serviço

2.1 · Landing de Conversão PRONTO

Página única de alta conversão, mobile-first, para lançamento, evento, serviço específico ou destino de tráfego pago.

O que inclui
Copy de conversão, hero, prova social, seção de oferta, botão de WhatsApp fixo, formulário → planilha/e-mail, rastreamento de eventos completo, animações de rolagem, favicon e OpenGraph.
Base técnica
HTML/CSS/JS estático, sem build. Deploy automático por FTP via GitHub Actions (push na main → TurboCloud). Fontes Google, imagens otimizadas (WebP).
Esforço
16–24h de produção · prazo 4–7 dias corridos.
Entregável
Site no ar em domínio do cliente + repositório + acesso ao rastreamento.
Valor pro cliente
Destino que converte tráfego em contato/venda, com números provando o que funciona. Sem depender de construtor lento.

2.2 · Site Institucional PRONTO

Presença completa para clínica, escritório, imobiliária, comércio ou prestador — 4 a 7 páginas com SEO on-page e captação de contato.

O que inclui
Home, sobre, serviços, contato, + páginas específicas. SEO on-page (títulos, meta, headings, sitemap). Formulário → banco próprio no Supabase + tela simples de leads. Rastreamento completo. Blog opcional.
Base técnica
Mesma stack estática + Supabase para os leads (tabela com RLS, sem SaaS de formulário no meio). Mini-CMS é add-on.
Esforço
40–70h · prazo 2–3 semanas.
Entregável
Site + painel de leads + documentação de acesso.
Valor pro cliente
Presença séria, encontrável no Google, que já começa a capturar contato em vez de só “existir”.

2.3 · CRM de WhatsApp — Pipeline (Fase 1) PRONTO

Tela privada, com login, onde a equipe gerencia os leads de verdade: pipeline Kanban, carteira por vendedor, status editável.

O que inclui
Login por e-mail/senha (Supabase Auth). Pipeline com etapas (novo → contato → conversando → proposta → ganho/perdido). Atribuição por vendedor com isolamento (cada um vê só a carteira dele; gestor vê tudo e distribui). Botão “urgente” (outro vendedor ajuda sem roubar a venda). Tela de gestão de equipe (gestor cadastra/desativa vendedor sozinho). Trocar senha pela própria tela.
Base técnica
Supabase (Postgres + Auth + RLS por papel), Edge Functions para operações administrativas, front-end estático. Segurança: nível de linha no banco — chave pública não lê dado de contato.
Esforço
Setup por cliente: 8–14h (projeto Supabase, SQL, deploy, cadastro de equipe, treino).
Entregável
CRM no ar + contas da equipe + treino de uso.
Valor pro cliente
Fim do “vendedor saiu e levou a carteira na cabeça”. Gestor enxerga quem está com o quê. Base é a razão da mensalidade.

2.4 · CRM de WhatsApp — Inbox / API oficial (Fase 2) RECEBE · ENVIO EM CURSO

Conta oficial da Meta (WhatsApp Business Platform) conectada ao CRM: as mensagens entram no sistema 24h/dia e aparecem numa inbox tipo chat.

O que inclui
Abertura da conta oficial (verificação de negócio, número, WABA, templates, publicação do app). Webhook recebendo toda mensagem numa tabela. Inbox no CRM: lista de conversas + thread formatado tipo WhatsApp, na mesma página do pipeline. Envio de resposta pelo próprio CRM (em finalização — depende de token permanente + forma de pagamento na conta).
Base técnica
Meta Cloud API oficial (sem risco de banimento, diferente das conexões por QR). Edge Function whatsapp-webhook no Supabase, mesmo padrão das outras integrações.
Esforço
Onboarding Meta: 8–16h de calendário (verificação leva 1–5 dias úteis do lado da Meta).
Entregável
Número oficial ativo + inbox no CRM + histórico permanente de conversas.
Valor pro cliente
Nenhuma conversa se perde. Histórico fica no sistema, não no aparelho de um vendedor. Base para IA de triagem depois.

Custo operacional baixo: conversa iniciada pelo cliente é gratuita na Meta desde nov/2024. Só template proativo (reativação de base) tem custo, na casa de centavos por conversa.

2.5 · Rastreamento & Analytics PRONTO

Todo evento do site é enviado para dois lugares ao mesmo tempo: o Meta Pixel (otimização de anúncio) e um banco próprio (análise sem depender de terceiro).

O que inclui
Meta Pixel + CAPI. Eventos: PageView, clique no WhatsApp (Contact), início de checkout, rolagem, tempo na página, play/progresso/fim de vídeo. Captura de UTM, gclid e fbclid na entrada. Painel interno: visitantes, sessões, funil, campanhas por UTM, ROI (investido × vendas via webhook de checkout).
Base técnica
Coletor próprio no Supabase (tabela events, insert anônimo via RLS) + Edge Function de enriquecimento por geolocalização de IP. Dashboard estático lendo funções agregadas (sem PII exposta).
Esforço
Incluso na entrega de site (2–4h de configuração).
Entregável
Rastreamento ativo + acesso ao painel.
Valor pro cliente
Para de “achar” e passa a “ver”: de qual canal veio cada venda, o que o tráfego pago realmente traz, onde o funil vaza.

2.6 · Funil de Captação — Quiz PRONTO

Ferramenta de perguntas e respostas que engaja o visitante e entrega um lead qualificado direto no banco do cliente — sem SaaS de formulário no meio.

O que inclui
Fluxo de contato-primeiro (nome/WhatsApp antes das perguntas, para não perder o lead se abandonar), classificação por nível/pontuação, resultado personalizado com CTA, disparo de evento para o Pixel, gravação no banco do cliente.
Base técnica
Página estática + Supabase (tabela quiz_leads com PII protegida por RLS). Padrão de dupla gravação para não perder lead incompleto.
Esforço
12–20h (roteiro das perguntas + montagem + integração).
Entregável
Quiz no ar + leads caindo no painel.
Valor pro cliente
Isca de melhor custo por lead que PDF estático. Qualifica antes de o vendedor gastar tempo.

2.7 · Gestão de Tráfego OPERACIONAL

Aquisição paga terceirizada: Meta Ads e Google Ads ligados ao rastreamento e ao CRM, com relatório de ROI puxado do próprio painel.

O que inclui
Configuração de Pixel/CAPI, públicos (personalizado da base + lookalike), banco de criativos inicial, gestão e otimização contínua, relatório mensal de investido × retorno.
Base técnica
Sempre alinhado às políticas oficiais da Meta (rate limiting, permissões mínimas, conta verificada) para não arriscar bloqueio.
Esforço
Setup 8–16h + gestão contínua.
Entregável
Campanhas rodando + relatório mensal.
Valor pro cliente
Um só responsável por site, dado e mídia — o resultado não se perde entre fornecedores.

04 — INFRAESTRUTURA

A stack por trás

Hospedagem & deploy

  • TurboCloud (hospedagem compartilhada) — sites estáticos, custo marginal por site baixo.
  • GitHub + GitHub Actions — versionamento e deploy automático por FTP a cada push.

Backend & dados

  • Supabase — Postgres, autenticação, segurança por linha (RLS), Edge Functions. Plano gratuito cobre site pequeno + CRM pequeno; plano pago (US$ 25/mês) quando o cliente cresce ou exige isolamento total.
  • Estratégia atual: um projeto Supabase por cliente (isolamento simples). Multi-tenant de verdade — uma infra, cliente por linha — é evolução para quando a carteira passar de ~5–10 clientes.

WhatsApp & mídia

  • Meta WhatsApp Business Platform (Cloud API oficial) — sem risco de banimento. Cada cliente com WABA + número + app próprios.
  • Meta Ads / Google Ads — para a entrega de tráfego.
  • Para escalar o onboarding sem trabalho manual em cada cliente: caminho é virar Tech Provider da Meta (o cliente conecta o número dele por um fluxo embutido).

Regra de ouro: a criação precisa pagar o seu tempo mesmo que a recorrência demore a somar. A recorrência é o ativo — trate-a como o produto, a criação como a entrada. Sempre apresente o Pacote 3 primeiro: ele ancora e faz o Pacote 1 parecer barato.

Projeção conservadora (12 meses)

Fechando por mês 2× Pacote 1, 1× Pacote 2, 1× Pacote 3, com churn de 3%/mês sobre a base:

  • Mês 1: ~R$ 19.400 de criação + R$ 1.520 de recorrência = R$ 20.920.
  • Mês 12: ~R$ 14.000/mês só de recorrência (R$ 168 mil/ano) + R$ 18–22 mil/mês de criação.
  • No mês 12, a carteira recorrente vale mais que a soma de todos os projetos de criação do ano — e continua rendendo mesmo se a prospecção parar.
06 — ROADMAP

O que vem depois

Fase 3 — IA de triagem no WhatsApp

Assistente (“Cris”) que responde automaticamente só perguntas de logística (preço, data, horário, forma de pagamento, certificado) e escala qualquer outra coisa — inclusive qualquer sinal de dúvida clínica ou sensível — para o humano. Sempre se identifica como IA, com opção de falar com pessoa. Reduz carga da equipe sem risco de a IA falar o que não deve.

Multi-tenant

Migrar de “um Supabase por cliente” para uma infraestrutura única com cliente por linha, autenticação por organização e cobrança automatizada. Só quando a fila de clientes justificar as semanas de trabalho.

Meta Tech Provider

Status que permite onboarding self-service do número do cliente — elimina as horas de configuração manual por cliente. É o desbloqueio para escalar o Pacote 3.

07 — TRAVAS OPERACIONAIS

Resolver antes de vender pesado

Nenhuma impede começar. Todas comem margem se ignoradas.

  • Sem CMS = gargalo de conteúdo. Toda alteração de texto/foto é edição de código + deploy. Decidir o modelo: franquia de alterações no plano, mini-CMS nos tiers médios, ou construtor nos tiers baixos.
  • CRM single-tenant. Funciona até ~5–10 clientes com um Supabase cada. Além disso, multi-tenant.
  • Onboarding Meta é caro em tempo. Cobrar a implementação alto o suficiente. A médio prazo, Tech Provider.
  • Suporte sem processo é prejuízo. Canal único (não WhatsApp pessoal), horário, SLA por tier, escopo do que “manutenção” inclui.
  • Contrato. Dois documentos: criação (escopo, revisões, prazo, propriedade do código) e mensal (o que inclui, reajuste anual, cancelamento com aviso de 30–60 dias, exportação dos dados do CRM na saída).
